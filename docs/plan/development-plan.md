## 里程碑

### M1 地基: 账号全链路 + 游戏集成 + 路由兼容

- 目标: 注册（邀请码/游戏库同步/邮件激活）、登录（phpass 无感升级）、找回改密（双写游戏库）、用户中心 8 页、游戏四库直连、SOAP 命令层、301 路由兼容层
- 验收标准: **100 老用户真实登录成功率 100%（无感）**
- 预估工作量: 2-3 周
- 状态: **未开始**

### M2 营收: 积分体系 + 商城全链路 + 后台最小集

- 目标: 积分账本（余额+流水+对账）、商品/分类（含库存/促销/SKU 校验）、购物车、结账（角色校验+积分支付+SOAP 发货+状态闭环）、装备恢复等 9+ 服务处理器、后台商品/订单/用户/积分手调
- 验收标准: **测试订单全链路（下单→扣分→SOAP 发货→completed）+ 积分对账差异清零**
- 预估工作量: 2-3 周
- 状态: 未开始

### M3 社区: 论坛 + 内容资讯 + 全局框架完善

- 目标: 5 版块论坛（主题/楼层/回帖传图/版主操作）、存量论坛与文章迁移、公告/资讯归档、渐进计划数据化时间轴、静态页 MDX、友情直播页、侧栏组件系统
- 验收标准: **存量论坛/文章可访问，旧 URL 301 全部生效**
- 预估工作量: 2 周
- 状态: 未开始

### M4 完善: 工具页 + 搜索 + 通知 + 横切

- 目标: rank 五工具页 iframe、全局搜索、通知中心+邮件模板、Turnstile+登录限速、统计看板、SEO sitemap
- 验收标准: **新旧并行观察 1 周（读新写旧）→ 切换上线**
- 预估工作量: 1-2 周
- 状态: 未开始

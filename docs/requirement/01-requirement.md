## 1. 项目定位

老克塔（lokta.cn）官网重开发：魔兽世界 60 年代怀旧服（AzerothCore 引擎）社区门户，"怀旧公益项目"。替代生产 WordPress 系统（PHP 已过时，旧 WordPress 仓库保留至切换下线）。

**目标用户**: 站内 6,330 注册玩家（站点账号=游戏账号）；游客（经邀请码注册的新玩家）

**核心价值**: 四类职责一体——① 社区门户（资讯/教程/论坛/直播）② 游戏数据服务（排行榜/在线玩家/封号记录）③ 玩家自助服务（注册开号/角色查询/物品恢复）④ 虚拟商品商城（积分支付+SOAP 游戏内自动发货）。与游戏世界（四库直连+SOAP 命令通道）的深度集成是外部替代品不具备的。

**三条铁律**（贯穿所有模块）:
1. 站点用户名 = 游戏账号名，注册即同步写入游戏 auth 库（单向 站点→游戏）
2. 一切涉及密码/账号的变更必须双写（站点 + 游戏 auth 库）
3. 商品 SKU `itemsend_{游戏物品ID}` 是商城与游戏世界的映射契约

## 3. 明确不做清单

- **物品类商品寄送他人角色**（现状 acore_msg_dest 能力）——D6 决策（2026-10-23）：物品一律寄下单所选角色
- **微服务架构**——6K 用户规模，单体优先
- **页面构建器**（Elementor 式）——内容一律 Markdown/MDX，仅 2 页在用且直接转换
- **pmpro 订阅体系**——现状休眠（未安装），数据归档不迁
- **站点与游戏密码解除同密**——D2 默认保持同密契约（可复议）
- **多语言**——现状单语言，无此需求
- **爬取视频/资讯本体转存与二次分发**（2026-11-09 二期裁定）——聚合只采公开元数据与原站外链，播放走外链；不转存视频本体、不做二次分发（版权、存储与带宽三重不可行）
- **账号养号 / 批量注册 / 绕付费墙 / 破验证码**（2026-11-09 二期裁定）——短视频源走与 aitech-hub 同款的**签名网关**（公开内容接口调用）已获用户确认；但**不养号、不批量注册、不绕付费墙、不破验证码、不破反爬**；robots 明确禁止的源不采
- **MCP 通用数据写入**（2026-11-09 二期裁定）——只暴露白名单业务工具，不提供任意 SQL / 通用表写入 / 删档能力（商品不可逆操作一律用「下架」代替删除）

## 4. 非功能需求

| 维度 | 要求 |
|------|------|
| 兼容 | 老用户登录体验零变化（phpass 透明升级，M1 验收=100 老账号真实登录成功率 100%） |
| 安全 | 腾讯云验证码 TCaptcha（登录/注册）+ 登录限速 + 会话安全；游戏库凭据仅环境变量 |
| SEO | 语义化 URL + 301 兼容层全覆盖（旧 URL 有外部/教程硬编码引用）+ sitemap |
| 备份 | 服务器 cron mysqldump + rsync/对象存储（对齐本次备份流程，research/01 §7） |
| 性能 | 6K 用户规模；静态化/缓存策略自定，非硬性移植项 |
| 可靠 | SOAP 发货失败必须可见：重试队列 + 告警 + 人工补发入口（现状 1,895 单静默滞留是反面教材） |

## 5. 验收标准

- 每里程碑验收锚点见 [plan/development-plan.md](../plan/development-plan.md)，均为可执行可验证条目
- M1：100 老用户真实登录成功率 100%（无感）
- M2：测试订单全链路（下单→扣分→SOAP 发货→completed）+ 积分对账差异清零
- M3：存量论坛/文章可访问，旧 URL 301 全部生效
- 上线：新旧并行观察 1 周（读新写旧）→ 切换
- M6（MCP）：令牌鉴权生效 + 白名单工具全量可用 + 每次调用可审计 + 商品写入与后台表单走同一校验（违规 SKU 同样 422）
- M7（内容聚合）：至少 2 个源稳定产出条目 + 去重零重复 + 前台信息流可筛选来源 + 抓取失败有告警与重试记录
- M8（站内搜索）：跨类型（资讯/攻略/帖子/商品/聚合条目）分组结果页可用 + 命中面含标题与正文 + 站内搜索词可进统计
- M9（AI 助手）：回答必附来源链接 + 检索不到时明说而非编造 + LLM 通道故障自动降级到站内搜索/FAQ + 日配额生效

## 6. 二期待用户确认项（2026-11-09 汇总）

| # | 事项 | 状态 | 结论 |
|---|---|---|---|
| 1 | **短视频源（B站/抖音）的采集方式** | **已定（2026-11-09）** | **仿 aitech-hub**：独立 Python 网关 sidecar 做平台接口签名（a_bogus/wbi）+ Cookie 池 + 出口代理轮换；本项目侧只做 HTTP 契约调用。**边界同 aitech-hub：只做基本信息索引与转发，不做存储**（播放地址过境即焚、视频本体不转存） |
| 2 | **封面图热链 vs 转存 COS** | **已定（2026-11-09）** | **热链 + 失败回退占位图**，不存 COS |
| 3 | **LLM / embedding 供应商与首批密钥** | 待提供 | 通道协议已定（anthropic + openai 兼容，后台自定义），具体供应商与密钥需用户提供；建议 embedding 与 chat 同家（少一套密钥） |
| 4 | **向量存储形态** | **已定（2026-11-09）** | MySQL 存 embedding + 进程内召回，**不引入 pgvector**；语料超 5 万条或召回延迟不达标时，重评 PG + pgvector sidecar |
| 5 | **Agent 框架选型** | **已定（2026-11-09）** | **deepagents**（LangChain 官方 TS 包），最小配置用：只挂规划与护栏中间件、禁用文件/Shell/沙箱后端、不接 LangGraph checkpointer（会话历史自存 MySQL）；退路 = LangGraph 原生 StateGraph |

# Feature Specification: M3 社区 — 论坛 + 内容资讯 + 全局框架完善

**Feature Branch**: `003-m3-community`

**Created**: 2026-10-24

**Status**: Draft（澄清待裁决，见 §7）

**Input**: 飞书需求池 M3-社区 24 条（20 待开发 / 4 已取消）+ 规格 §2/§7/§8/§12/§13/§14 + 迁移方案 §2 + 原型 p02/p07/p13/p15

## User Scenarios & Testing *(mandatory)*

### US1 全局框架完善（导航/页头/页脚/响应式/侧栏）

M1 缺口顺延项 + 全站壳层：

- **登录态双菜单导航（P0）**：游客菜单去掉账户/商店入口、突出登录注册；登录菜单含我的账户/购物车/结账
- **多级菜单结构（P0）**：结构照搬旧站——首页｜项目简介/使用教程(锚点)｜公告▾(开发日志/渐进计划/封号记录)｜数据库▾(英雄榜/在线玩家/在线地图/DKP查询)｜资讯｜论坛｜积分商店｜我的帐户▾(购物车/结账)
- **页头（P1）**：Logo + 站名 + 副标题 + 随机魔兽角色头图（每次刷新随机，数据源 acore_characters）
- **页脚（P1）**：简单页脚（协议/公约/备案）
- **移动端响应式（P0）**：汉堡折叠菜单 + 核心页响应式布局
- **侧栏组件系统（P1）**：可配置侧栏，§2.1 十二组件（搜索框/公告图链/客户端下载/登录器下载/YY频道/外部三链/插件下载/日历归档/积分余额(登录)/最近浏览商品）
- **Wowhead 物品提示（P1）**：文章正文内 `[wowhead id]` 短代码或链接悬浮浮窗（商品详情页 M2 已实现，此处补文章内）

### US2 内容域模型与存量迁移（P0 迁移）

- 数据模型：article（文章）/ content_page（静态页）/ category / tag / article_views（阅读数**必迁**，前台有展示）
- 存量迁移管线（幂等可重跑，沿用 M2 模式）：wp_posts(post/page) 111+20 篇 → article/content_page；wp_terms → category/tag（文章 4 分类）；wp_post_views → article_views；wp_comments 2,089 按归属拆分（文章评论部分后置不迁，仅保留映射盘点）
- 正文 HTML → 结构化存储 + 图片 URL 重写（复用 M2 image_asset_map / cos-upload 管线与死链扫描）
- 语义化 URL：`/post/{slug}`、归档 `/announcements` `/news` `/guides`；301 兼容层扩展（`?p=` → `/post/{slug}` 逐 id 映射、`?cat=` → 归档、静态页 page_id 逐页映射）；sitemap

### US3 内容前台（P1）

- **首页重设计（P1）**：聚合 公告最新 + 服务器状态卡 + 当前渐进阶段 + 精选商品（现状首页正文为空，属升级项）
- **归档列表（P1）**：公告 28 / 资讯 67 / 资料梳理 15，10 篇/页+分页
- **文章详情（P1）**：正文渲染 + TOC + 阅读计数 + Wowhead 提示（评论 P2 后置不实现）
- **渐进计划页数据化（P1）**：阶段/节点表（标题/显式日期/配图/富文本/开放状态/排序）+ 前台按日期排序时间轴 + 当前/下一阶段锚点导航 + 29 存量条目迁移
- **静态页（P1）**：项目简介/使用教程(三下载锚点+截图)/用户协议/和谐公约/网站地图——存储口径见澄清 Q2
- **开发日志**：转普通文章分类归档

### US4 内容后台（P0 编辑/P1 文件夹）

- Markdown 编辑器：GFM + 代码高亮 + 粘贴图片自动上传 COS + TOC 预览（P0）
- 文章/页面 CRUD + 分类标签管理（P0）
- 媒体库最小集（P1）：列表/上传/删除 + 正文引用插入；文件夹管理后置
- p15 原型的区块化编辑器/版本历史/审核流**不在 M3**（YAGNI，见澄清 Q4）

### US5 论坛（迁移 P0 / 前台 P1 / 版主 P1）

- 数据模型：forum_board / thread / post（楼层）
- 存量迁移（P0）：5 版块 / 259 主题 / 471 回复，保留作者/时间/状态前缀；附件图片 URL 重写
- 前台浏览（P1）：版块列表 → 主题列表（分页）→ 主题详情（楼层+回帖序号）；`/forum/...` 路由 + `/bbs`、`?topic=`、`?forum=` 301
- 版主操作（P1）：置顶/关闭/删除 + 审计留痕；状态标签见澄清 Q3
- **发帖/回帖/传图：需求池已取消**——论坛交互边界见澄清 Q1

### US6 服务器状态组件（P1）

- 首页状态卡数据源：SOAP 探针实时字段（在线数/运行状态/阵营比/登录队列/今日峰值/稳定运行）+ characters 库统计（角色总数/今日新注册）+ 后台人工配置 3 项（当前阶段/维护模式/展示开关）
- 字段二分口径按 p15 定案：接口拿得到的不提供编辑，后台只管语义配置；探针离线显示「数据延迟」

## Requirements *(mandatory)*

### Functional Requirements

**全局框架**
- **FR-201**：导航按登录态渲染双菜单；游客点商店/账户入口引导登录注册
- **FR-202**：多级菜单结构照搬旧站（含两个下拉组：公告▾/数据库▾；我的帐户▾ 仅登录态）
- **FR-203**：页头随机角色头图从 acore_characters 只读抽样，失败降级默认图
- **FR-204**：全站页脚含协议/公约/备案链接
- **FR-205**：移动端汉堡菜单可折叠展开全部层级
- **FR-206**：侧栏组件化渲染，组件清单可按页面类型配置；积分余额组件仅登录态显示、最近浏览商品基于本地浏览历史
- **FR-207**：文章正文 Wowhead 物品提示悬浮浮窗，离线/加载失败降级纯文本

**内容域**
- **FR-208**：article/content_page/category/tag/article_views 模型；迁移幂等可重跑
- **FR-209**：归档列表分页 10 篇/页；归档路由 `/announcements` `/news` `/guides`
- **FR-210**：文章详情 `/post/{slug}`；TOC 锚点导航；阅读计数原子累加且去重口径明确（见澄清 Q7）
- **FR-211**：渐进计划时间轴按显式日期排序；当前/下一阶段锚点导航；后台可增改删
- **FR-212**：静态页 5 页可达（存储口径见澄清 Q2）
- **FR-213**：`?p=`/`?cat=`/静态页 page_id 301 映射全量生效；sitemap 生成
- **FR-214**：首页聚合公告/服务器状态/当前渐进阶段/精选商品四区块

**内容后台**
- **FR-215**：Markdown 编辑器支持 GFM+代码高亮+粘贴图片自动上传 COS+TOC 预览
- **FR-216**：文章/页面 CRUD 走 requireAdmin 守卫+审计；发布/草稿状态机
- **FR-217**：媒体库列表/上传/删除/正文插入（COS 复用 M2 lib/cos）

**论坛**
- **FR-218**：forum_board/thread/post 模型；迁移保留作者/时间/状态前缀，附件 URL 重写，幂等可重跑
- **FR-219**：论坛前台浏览路由 `/forum`、`/forum/{board}`、`/forum/thread/{id}`；`/bbs` 与 `?topic=`/`?forum=` 301
- **FR-220**：版主置顶/关闭/删除操作 requireModerator 守卫+审计留痕（交互边界见澄清 Q1，标签见 Q3）

**服务器状态**
- **FR-221**：SOAP 探针实时字段 30s 刷新；探针离线降级「数据延迟」徽标；人工配置 3 项后台可改且写审计

## Success Criteria *(mandatory)*

- **SC-201**: 存量论坛 259 主题/471 楼层全量可访问，作者/时间/状态前缀保真；`/bbs` 与 `?topic=` 旧 URL 301 全部生效
- **SC-202**: 存量文章 111 篇 + 静态页 20 页全量可访问；`?p=` → `/post/{slug}` 301 全部生效；图片死链扫描 0
- **SC-203**: 阅读计数迁移后与 wp_post_views 对账一致；增量计数在并发下无损
- **SC-204**: 渐进计划 29 档数据化后前台渲染与旧页信息等价（阶段顺序/开放状态/锚点导航）
- **SC-205**: 游客与登录用户菜单集合断言互斥（双菜单）；多级菜单结构与旧站逐项一致
- **SC-206**: 后台 Markdown 发文→前台渲染（含代码高亮/图片/TOC）闭环；粘贴图片落 COS 可访问
- **SC-207**: 版主置顶/关闭/删除全留审计；越权操作 0 成功
- **SC-208**: 服务器状态探针在线/离线两态渲染正确；后台人工配置变更实时生效且留痕

## 适用宪法原则（合规映射）

- **原则 IV 兼容无感**：301 映射扩展与 SC-201/202 直接对应；静态页/教程截图硬编码旧路径必须在 M3 全量兜住
- **原则 V 数据边界**：游戏库只读（随机头图/状态探针）；渐进计划/内容走业务库
- **原则 VI 安全纵深**：版主 RBAC（M2 已有 moderator 角色）+ 审计；Turnstile 仍维持 M4 deferral
- **原则 VII 单体 YAGNI**：p15 区块编辑器/版本历史/审核流裁剪出 M3；评论后置
- **原则 VIII 测试必附**：迁移对账/301 全量/双菜单断言均有自动化锚点（SC-201~208）

## Assumptions

- 友情直播页已取消（2026-10-24 用户指令，需求+原型全量删除），M3 不含
- 文章评论（顶/踩）后置二期（需求池口径一致）；徽章系统前台展示已取消
- RBAC 沿用 M2：guest/user/moderator/admin，版主操作仅 moderator+admin
- 图片迁移完全复用 M2 image_asset_map + cos-upload 幂等管线，不新建机制
- Wowhead 文章内提示优先官方 tooltip 脚本（商品页 M2 已有降级先例）
